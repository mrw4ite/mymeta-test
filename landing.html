FAQ

Quick answers

What is included for free?−

Smart Tracking free on 2 pages, all free templates, visual builder, and custom HTML upload. No credit card required.

Does a button click count as a Telegram join?+

No! Unlike normal pixels, MyMeta only fires the Meta Conversions API event when the user actually sends a Join Request inside Telegram.

I already have a page. Can I use only the tracking?+

Yes! Turn on HTML Page mode, upload your index.html, and place our Smart Tracking Link in your CTA button href.

Can I decide whether repeat requests count?+

Yes, there is a dedicated "Count repeat requests" toggle when connecting your Telegram channel.
